# Cuanku

Aplikasi personal finance local-first untuk mencatat saldo JPY dan IDR.

Fitur meliputi dompet, transaksi, anggaran pengeluaran bulanan, laporan, dan backup lokal.

## Development

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Quality gates

```bash
npm run typecheck
npm test
npm run lint
npm run build
```
